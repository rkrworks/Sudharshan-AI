Complete Commands for a Fresh Fedora Linux Installation

Run the automated ./setup_fedora.sh installer or copy step-by-step commands below.

Option A — Automated One-Line Setup 
chmod +x setup_fedora.sh bajrang_llama32.py && ./setup_fedora.sh
Step 1 • Install Fedora DNF Packages 
sudo dnf update -y
sudo dnf install -y python3 python3-pip python3-gobject python3-pillow sqlite \
  gtk4 libadwaita pipewire-utils alsa-utils speech-dispatcher speech-dispatcher-utils \
  espeak-ng ydotool grim gnome-screenshot wl-clipboard gnome-extensions-app curl git
pip3 install --user --upgrade faster-whisper
Step 2 • Configure /dev/uinput & ydotoold Daemon 
echo 'KERNEL=="uinput", GROUP="input", MODE="0660", OPTIONS+="static_node=uinput"' | \
  sudo tee /etc/udev/rules.d/80-uinput-bajrang.rules
sudo usermod -aG input,pipewire,audio "$USER"
sudo udevadm control --reload-rules && sudo udevadm trigger
ydotoold --socket-path=/tmp/.ydotool_socket --socket-perm=0600 &
Step 3 • Start Ollama & Pull Llama 3.2 
curl -fsSL https://ollama.com/install.sh | sh
sudo systemctl enable --now ollama
ollama pull llama3.2
Step 4 • Deploy Extension & Launch HUD 
python3 bajrang_llama32.py --export-project ~/bajrang-ai
python3 bajrang_llama32.py --install-gnome-extension
gnome-extensions enable bajrang-ai@fedora.local
~/bajrang-ai/run.sh
