# ⚡ Bajrang AI Pro (Argon Edition) — Fedora GNOME Assistant & Web Store

**Bajrang AI Pro** is a privacy-first, voice-enabled desktop assistant and commercial GNOME Shell 45–49 Top-Bar Extension built natively for **Fedora Workstation (GNOME / Wayland)**.

## ✨ Key Capabilities
- **Dual AI Engine (Local Llama 3.2 or Free BYO API Key)**:
  - Run 100% offline with a personalized `bajrang-llama3.2` Ollama model tuned for your hardware.
  - Or enter your own **Google Gemini Argon / 2.5 Pro**, **Groq**, **OpenRouter**, or **OpenAI** API key to run in the cloud for free.
- **Custom PipeWire 8-Band Spectral-DTW Voice Recognizer**:
  - Captures 16 kHz mono PCM audio natively via Fedora PipeWire (`pw-record`), performs RMS dBFS + Zero-Crossing VAD, and matches 8-band Goertzel spectral envelopes using Dynamic Time Warping (DTW) alongside `faster-whisper` STT and `spd-say` TTS.
- **Persistent SQLite3 Local Chat History**:
  - Stores every conversation session, voice transcript, and action execution log in `~/.local/share/bajrang-ai/history.db` with instant full-text search.
- **Bright Mode & Dark Mode**:
  - Seamless Adwaita light/dark switching in both the GTK4 floating HUD (`--toggle-theme`) and the web portal (`index.html`).
- **Wayland Automation & Safety Guardrails**:
  - Synthetic Wayland mouse/keyboard automation via `ydotoold` (`/dev/uinput`), strict non-root command blocklist, and instant `Ctrl+Escape` Emergency Kill-Switch.

Fresh Fedora Workstation Setup & Lenovo Yoga 7i Tuning

          

            Automated setup for Fedora 41/42 GNOME Wayland, including PipeWire voice tools, /dev/uinput permissions, and optional Lenovo Yoga 7i Dolby Atmos woofer pin fix.
          

        

        
      


      

        

          Automated Full Installer
          
        

        
chmod +x setup_fedora.sh bajrang_llama32.py && ./setup_fedora.sh

      


      

        

          

            Step 1 • Fedora DNF Packages (GTK4, PipeWire, ydotool)
            
          

          
sudo dnf install -y python3 python3-pip python3-gobject python3-pillow sqlite \
  gtk4 libadwaita pipewire-utils alsa-utils speech-dispatcher speech-dispatcher-utils \
  espeak-ng ydotool grim gnome-screenshot wl-clipboard gnome-extensions-app curl git
pip3 install --user --upgrade faster-whisper

        


        

          

            Step 2 • /dev/uinput Udev Rule & ydotoold Daemon
            
          

          
echo 'KERNEL=="uinput", GROUP="input", MODE="0660", OPTIONS+="static_node=uinput"' | \
  sudo tee /etc/udev/rules.d/80-uinput-bajrang.rules
sudo usermod -aG input,pipewire,audio "$USER"
sudo udevadm control --reload-rules && sudo udevadm trigger
ydotoold --socket-path=/tmp/.ydotool_socket --socket-perm=0600 &

        


        

          

            Step 3 • Build Personalized Llama 3.2 Model in Ollama
            
          

          
curl -fsSL https://ollama.com/install.sh | sh
sudo systemctl enable --now ollama
ollama pull llama3.2
python3 bajrang_llama32.py --build-personalized-llama

        


        

          

            Step 4 • Enable GNOME Extension & Launch HUD
            
          

          
python3 bajrang_llama32.py --export-project ~/bajrang-ai
python3 bajrang_llama32.py --install-gnome-extension
gnome-extensions enable bajrang-ai@fedora.local
~/bajrang-ai/run.sh
