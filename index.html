Frequently asked questions

Technical specifications and hardware requirements for desktop automation.

Verified for Windows 11 (22H2+) and Fedora Workstation (GNOME 45–49).

Does the assistant require an internet connection?

No. The core engine runs completely offline with Ollama (Llama 3.2) and local SQLite storage. An internet connection is only needed if you configure external cloud API keys.

How does the safety guard prevent shell escalation?

The engine runs with fail-closed allowlisting without shell subprocesses. It blocks metacharacters and privilege escalation, and child processes immediately terminate when pressing Ctrl+Escape.

Which packages run on Fedora Workstation?

Fedora Workstation 39 to 42 with GNOME Shell 45 to 49, PipeWire for audio capture, and ydotool with a running ydotoold daemon for Wayland input synthesis.

Where does the vault store encryption keys?

Chat logs are kept in local SQLite databases in WAL mode. API keys are encrypted in OS-level hardware credential vaults such as Windows Credential Manager and GNOME Keyring.

How does the server sign Pro license keys?

Purchases through Razorpay generate a genuine server-signed RSA cryptographic certificate that verifies locally on your device without transmitting telemetry.
