Complete Commands for a Fresh Fedora Linux Installation

Run the automated bash setup_fedora.sh script or copy every individual step below on a brand-new Fedora Workstation (GNOME / Wayland) install.

⚡ Option A — Automated One-Script Installer (Recommended) 
chmod +x setup_fedora.sh bajrang_llama32.py && ./setup_fedora.sh
Step 1 • Install Fedora DNF Packages (GTK4, Libadwaita, PipeWire, ydotool) 
sudo dnf update -y
sudo dnf install -y python3 python3-pip python3-gobject python3-pillow sqlite \
  gtk4 libadwaita pipewire-utils alsa-utils speech-dispatcher speech-dispatcher-utils \
  espeak-ng ydotool grim gnome-screenshot wl-clipboard \
  gnome-extensions-app gnome-shell-extension-common curl git

# Optional local Whisper STT for open-ended voice dictation:
pip3 install --user --upgrade faster-whisper
Step 2 • Configure /dev/uinput & Start ydotoold Daemon 
echo 'KERNEL=="uinput", GROUP="input", MODE="0660", OPTIONS+="static_node=uinput"' | \
  sudo tee /etc/udev/rules.d/80-uinput-bajrang.rules
sudo usermod -aG input,pipewire,audio "$USER"
sudo udevadm control --reload-rules && sudo udevadm trigger

# Launch ydotoold socket daemon in background:
ydotoold --socket-path=/tmp/.ydotool_socket --socket-perm=0600 &
Step 3 • Install Ollama & Pull Local Llama 3.2 Model 
curl -fsSL https://ollama.com/install.sh | sh
sudo systemctl enable --now ollama
ollama pull llama3.2
Step 4 • Export Project, Install GNOME Extension & Enroll Voice 
# Export modular project + install GNOME Shell 45-49 extension:
python3 bajrang_llama32.py --export-project ~/bajrang-ai
python3 bajrang_llama32.py --install-gnome-extension
gnome-extensions enable bajrang-ai@fedora.local

# Enroll custom voice command & launch Floating HUD:
python3 bajrang_llama32.py --enroll-voice "open terminal"
~/bajrang-ai/run.sh
