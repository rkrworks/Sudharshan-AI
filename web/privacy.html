Privacy Policy

Last updated: November 2026

1. Local-First Architecture

Bajrang AI Pro is engineered from first principles to prioritize device isolation. Chat sessions, user preferences, and memories are persisted exclusively in a local SQLite3 database on your host operating system using Write-Ahead Logging (WAL) mode.

2. Zero Remote Telemetry

The desktop software transmits no tracking metrics, usage analytics, or session recordings to central servers. When you run local models via Ollama (Llama 3.2), all inference execution remains entirely on your machine.

3. Credential Storage

Optional third-party cloud API keys are stored in native operating system credential vaults (Windows Credential Manager on Windows 11; Secret Service API / GNOME Keyring on Fedora Linux). Plaintext secrets are never committed to disk logs.

4. Screen & Audio Capture

Screen grabs and microphone audio streams are processed in-memory for requested assistant tasks and discarded immediately. No continuous background recording is ever performed.
