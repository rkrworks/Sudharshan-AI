New CLI workflows

Ten local tools for daily work

Each command uses local files or databases. File organization and duplicate checks only report a plan.

01 · tasks

Lists and exports tasks

Add natural-language tasks, filter them by status, or export pending tasks to iCalendar.

python3 sudharshan_cli.py tasks --db tasks.db list

02 · vault

Maps Markdown backlinks

Index a notes folder and report wikilinks as a local knowledge graph.

python3 sudharshan_cli.py vault "$HOME/Notes"

03 · git

Summarizes Git changes

Show staged, unstaged and untracked files, with an optional commit-message suggestion.

python3 sudharshan_cli.py git --repo . --suggest-commit

04 · symbols

Searches code symbols

Find Python, JavaScript, TypeScript, Rust, Go and C symbols in a local codebase.

python3 sudharshan_cli.py symbols main --root .

05 · redact

Redacts sensitive text

Mask recognized API keys, card numbers and private addresses from text read on stdin.

cat notes.txt | python3 sudharshan_cli.py redact

06 · archive-inspect

Inspects archive entries

List files inside ZIP and TAR archives without extracting them.

python3 sudharshan_cli.py archive-inspect release.zip

07 · dedupe-report

Finds identical files

Compare local file hashes and report duplicates without deleting or moving files.

python3 sudharshan_cli.py dedupe-report "$HOME/Downloads"

08 · disk-report

Reports reclaimable caches

List build and language caches that can be reviewed before cleanup.

python3 sudharshan_cli.py disk-report "$HOME/Projects"

09 · schedule-preview

Previews cron schedules

Convert supported schedules to a cron line; the command is never installed or run.

python3 sudharshan_cli.py schedule-preview 'daily at 18:30' --command 'python3 backup.py'

10 · organize-preview

Previews file organization

Group a folder's files by extension and print proposed moves without changing files.

python3 sudharshan_cli.py organize-preview "$HOME/Downloads"

Local execution path

The permission boundary stays visible

Commands use local modules. Previews and reports do not execute shell instructions or alter files.

Review before changing files

Organization and duplicate scans are report-only in these CLI workflows. Archive inspection reads member names without extraction.
