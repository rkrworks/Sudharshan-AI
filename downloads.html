🛡️ Windows SmartScreen & Security Guidance

If Windows Defender or Microsoft SmartScreen flags downloaded scripts or batch files, here is why that happens and how to safely proceed:

Why does Windows display "Windows protected your PC"?
Microsoft SmartScreen evaluates files downloaded via web browsers based on commercial Authenticode reputation. Free, open-source community software that does not purchase an expensive annual enterprise EV certificate is flagged by default via browser Mark-of-the-Web (Zone.Identifier).

To launch cleanly on Windows 11:

  1. Run Unblocker: Run unblock_files.bat in the download folder to clear browser Zone.Identifier tags automatically.
  2. Or Manual Unblock: Right-click setup_windows.bat → select Properties → check Unblock at the bottom → click Apply.
  3. SmartScreen Prompt: If SmartScreen appears, click More info → click Run anyway.
  4. Cryptographic Check: Verify the SHA-256 hash using the table below to guarantee your copy is authentic and unmodified.
