## 1. Current Release: Alpha v0.9 (Delivered & Verified)

- [x] **Universal Dual-OS Desktop Architecture**: Windows 11 (Win32/Tkinter) and Fedora Linux (GTK4/Libadwaita/Wayland).
- [x] **Zero-Cloud DSP Spectral-DTW Voice Engine**: Offline keyword spotting (<8ms latency) with spectral noise subtraction.
- [x] **2048-Bit RSA Asymmetric License Verification**: Cryptographically secure `BAJRANG-V6-` certificate parsing.
- [x] **Zero-Argument Launcher Allowlist**: Strict trampoline escape elimination.
- [x] **Multi-Cloud Router**: Dynamic switching between Local Ollama, Google Gemini, Groq, and OpenAI with latency probing.
- [x] **Non-Destructive Task Planner**: Safe file organization with `.bajrang_trash/` undo staging and duplicate detection.
- [x] **Universal Floating Assistant**: Always-on-top, compact micro-HUD (480x140), and clipboard assistant.
- [x] **Visual Automation Builder**: Condition-evaluated workflow pipelines with confirmation gates.
- [x] **System Intelligence & Provider Dashboards**: Live authentic hardware telemetry and token accounting.
- [x] **Developer Copilot**: Directory inspection, traceback analysis, and unified diff generation.
- [x] **Diagnostics & Recovery Centre**: Database PRAGMA integrity verification, backups, and diagnostic exports.

## 2. Beta v0.9.5 (Target: Q1 2027)

- [ ] **Multi-Monitor Coordinate Scaling**: Automatic high-DPI and multi-monitor display matrix normalization for Wayland and Win32 screen capture.
- [ ] **On-Device Whisper.cpp Acceleration**: Embedded C++ Whisper engine with Vulkan/OpenCL acceleration for continuous open-ended dictation.
- [ ] **Dynamic MCP (Model Context Protocol) Sidecars**: Standardized MCP client integration allowing local IDEs (VS Code, Cursor) to invoke Sudharshan tools directly.
- [ ] **Encrypted P2P Sync**: Peer-to-peer encrypted sync of conversation history and memories across user workstation and laptop via TLS.
